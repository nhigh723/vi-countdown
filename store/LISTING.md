# App Store listing — Countdown VI

Copy these fields into App Store Connect. The title, subtitle, and keywords
contain no "GTA", "Grand Theft Auto", or "Vice City". The description names
the game it counts down to (factual reference, with the unofficial
disclaimer) — that is standard for companion apps, but if App Review objects,
trim the description to "the biggest game launch of 2026" and keep the
disclaimer.
